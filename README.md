# Savings Account Management System (PF Project)

## 📘 Project Overview
This project is a console-based **Savings Account Management System** developed in **C++** as part of the **Programming Fundamentals (PF)** course.  
The program simulates a savings account over a user-defined number of months and manages deposits, withdrawals, tax deductions, and final reporting.

## ⚙️ Features
- Accepts **annual tax rate**, **initial balance**, and **number of months**
- Handles **monthly deposits and withdrawals**
- Prevents **negative values and overdrafts**
- Calculates **monthly tax (annual rate ÷ 12)**
- Displays **formatted monthly account details**
- Shows a **final account summary**
- Uses **arrays, loops, and functions** (PF course requirement)
